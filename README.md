# 📊 Business Insights Dashboard – Atliq (Hospitality Domain)

## 🔹 Project Overview

This project focuses on analyzing the business performance of Atliq in the hospitality domain using an interactive Power BI dashboard. It provides both overall and monthly insights to support data-driven decision-making.

## 🎯 Objective
* To track key performance metrics and business trends
* To analyze revenue, occupancy, ratings, and cancellations
* To provide actionable insights for improving operational efficiency

## 📁 Data Source
CSV files containing hospitality business data

## 🛠️ Tools & Technologies
* Power BI
* Data Transformation (Power Query)
* Data Modeling
* DAX (Data Analysis Expressions)

## 📈 Key Features
### 🔸 Overall Analysis
* Revenue, Occupancy Rate, Average Metrics
* High-level business trends and insights

### 🔸 Monthly Analysis
* Revenue, Occupancy Rate
* Average Rating & Cancellation Rate
* Day-wise Revenue Trends

## 💡 Business Value
* Helps identify performance trends and patterns
* Supports strategic decision-making
* Provides a clear and interactive view of business KPIs

## 🧠 Skills Demonstrated
* Data Cleaning & Transformation
* Data Modeling
* KPI Development using DAX
* Dashboard Design & Visualization
